  - Dummy (3): combat_passive, NOT non_combatant so it is attackable, but
    effectively harmless — the risk-free first-blood target.
  - Scout (18): first live foe; a fresh newbie wins cleanly, can KO a careless
    one. Carries crude short blade 10021.
  - Squatter (40): can KO an inattentive newbie; THE armor-drop foe — equips
    body 20068 (Bandit's Leather Vest) which ALWAYS drops (carried equipment
    bypasses itemdropchance), powering the loot-and-equip lesson. Club 10010.
  - Bruiser (90) / Lieutenant (130): outer-ring escalation. Lieutenant uses
    `leader` (rallies/warcries the crew). Weapons 10010 / 10014.
  - Captain (200): the boss. tank_taunter (taunt + kick-prone + rally + warcry
    + bash cascade, calls for help <20% HP, never flees). "Velk-lite" — Velk
    is statpool 300; 200 is a real fight meant to be beatable by a newbie
    carrying ONLY the spoke's granted gear. Carries bandit's longsword 10026.
    FINAL beatability tuning is a Phase D playtest task (needs Q32/Q33 gear).

Both questgivers (Vorn, Garve) are Opened per canon, each with one understated
visible mutation woven into the description (Vorn: slate-grey stone-hard skin on
hands/forearms; Garve: animal-lambent eyes that briefly catch the light).
