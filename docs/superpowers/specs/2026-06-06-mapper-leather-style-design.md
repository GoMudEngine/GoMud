## 1. Goal

Replace the current dark-amber tile map with an **aged tooled-leather / antique
cartographer** look: a worn calfskin hide with embossed (relief) tooling,
realistic craquelure, frayed edges, an ornate border + compass + legend, and
**biome- and exit-aware path styling** for every connection. Add **party-member
position markers**. Reads like a real map tooled into leather sitting on the
dark desk of the UI.

---

## 2. Surface & frame (the "hide")

- **Base:** dark calfskin radial gradient — `#43301d` (45%,36%) → `#2c1d11` (55%)
  → `#170e07` (100%).
- **Grain:** `feTurbulence` `fractalNoise` baseFrequency `0.85`, 2 octaves,
  `stitchTiles`, through a dark `feColorMatrix`
  (`0 0 0 0 0.05  0 0 0 0 0.035  0 0 0 0 0.02  0 0 0 0.6 0`), overlaid at
  `opacity 0.4`.
- **Frayed hide silhouette:** the leather is an **irregular polygon clip-path**,
  not a rectangle. Generated by walking an inset rect (margin ~4px) with ~12px
  steps, offsetting each vertex inward by `rnd()*fray` plus occasional deeper
  **nicks**. Locked params: `fray ≈ 3.4`, `nickChance ≈ 0.08`. A dark worn rim
  (`#0e0703`, width ~2.4) strokes the hide path. The dark desk shows through the
  frays. All texture layers (grain, sheen, craquelure, stains, vignette) are
  **clipped to the hide**.
- **Craquelure:** a fine **cell-network** — a jittered grid (step ~24, jitter ~9)
  of points; connect each to its right/down neighbour with a 2-segment jittered
  polyline; randomly skip ~16% for irregularity. Dark groove `#120a04`,
  width 0.3–0.7, `opacity ~0.32`; an occasional faint light lip (`#caa86a`,
  `opacity 0.10`) offset +0.5 for raised-crack realism.
- **Sheen:** soft cream radial highlight top-left (`#fff4d8`, ~0.09) for hide
  curvature. **Vignette:** radial black, transparent to ~`0.5` at the edge,
  clipped to the hide.
- **Stains/wear:** a few low-opacity warm-cream radial blotches (`#caa86a`, ~0.07).

### Emboss (relief tooling)
Core technique — every tooled element is drawn in **three passes**:
1. **shadow** copy offset `+d` in `#140b04` (`opacity ~0.55`),
2. **highlight** copy offset `−d` in `#efce8c` (`opacity ~0.45`),
3. **face** copy at origin in the element colour.
Locked emboss depth `d ≈ 0.6` (medium). Helpers: `embLine`, `embCirc`, `embText`
(see mockups). Applied to: border, compass, title, road/ridge paths, room
tokens, service glyphs, legend title.

### Border, title, compass, legend
- **Border:** embossed **double rule** (outer ~2.2, inner ~0.8) inset ~18/24px,
  with **corner stud circles** (embossed) and edge **graticule ticks**.
- **Title:** serif italic bold (`#e8d2a0`), embossed — `"<Zone Name>"` with a
  `"~ Level N ~"` subtitle line (driven by `cz`).
- **Compass rose:** embossed 4-point cross top-right, `"N"` label.
- **Legend:** small leather card bottom-left (`#241810` bg, gold border),
  embossed "Legend" title, rows: **Party member** (figure), **Bank/Shop/Store**
  (token + `$`), **Stairs ▲▼**, **Road / trail / water** (sample). *No "You are
  here" row — the current room is self-evident (raised).* Keep it small-scale.

**Palette tokens:** ink/gold `#c9a86a`, secondary `#9c8048`, title `#e8d2a0`,
room fill `#2a1d12`, label cream `#e8d8b8`, locked red `#d0633f`, water
`#6f99c0`, trail `#a98a55`, party verdigris `#6bb0a0`.

## 3. Rooms

- **Normal room:** embossed circle r≈6.5, fill `#2a1d12`, gold stroke (emboss
  `d*0.7`).
- **Service room:** embossed circle r≈7 + a faint outer ring r≈9.5 + an embossed
  gold glyph — `$` bank, `S` shop, `▢` storage (from existing `tags`). Priority
  bank > shop > trainer > storage.
- **Current room (raised — replaces the old red highlight):** a whisper of warm
  glow (`#e8c98a`, opacity ~0.07, r≈13) + an **outer emphasis ring** (emboss
  `d*1.3`) + a **raised token** (r≈7.5, lighter face `#3a2a18`, deep emboss
  `d*2.4`). Its **name label** shows in italic serif beneath it.
- **Room name:** native SVG `<title>` tooltip on every room (already in the
  snapshot as `name`); current room also shows the visible label.
- **Stairs (vertical exits):** faint gold **▲ (up) / ▼ (down)** ticks at the
  room's right corner (from `kind=vertical` exits).
- **Distance fog:** per-room opacity falloff by Chebyshev distance from the
  current room (d0=1.0, d1=0.92, d2+=0.74) so the local area pops.

## 4. Party-member markers

A small **verdigris figure** (head + shoulders, `#6bb0a0` on a dark `#1c2e2a`
token, emboss shadow) at the **corner** of any room that currently holds a
party member **on the current floor**. Verdigris contrasts with the gold tooling
so it reads instantly. Legend row: "Party member".

**Data:** the user's party members and their `RoomId`s (party system + the
existing GMCP Party module). Add party-occupied room IDs to the `Zone.Map`
payload (or a sibling field), filtered to rooms on the current floor that are in
the snapshot.

## 5. Connection types (per-exit path styling)

Every connection is styled by what we can infer from the exit. Render order:
biome path first, then door/gate/marker overlays.

| Type | Inferred from | Rendering |
|---|---|---|
| **Road** | endpoint biome city/town/road | embossed tan (`#c9a86a`, w≈3) + dotted dark centre |
| **Trail** | biome forest/swamp/marsh | dashed `#a98a55` (w≈1.5) + soft shadow |
| **Ford / waterway** | biome water/lake/river | dashed blue `#6f99c0` (w≈1.8) |
| **Ridge path** | biome hills/mountain | embossed `#a98a55` (w≈1.7) |
| **Plain** | (fallback) | embossed `#9c8048` (w≈1.5) |
| **Highway (long)** | `kind=long` (`-x2/-x3`) | road style, longer run, **two league ticks** at ~0.38/0.62 |
| **Locked door** | `exit.Lock.Difficulty > 0` | near half dashed ink, **far half dashed red** (`#d0633f`), a small **keyholed arched-top door** icon at the midpoint (dark fill, gold emboss, red keyhole + plank seam) |
| **Secret passage** | `exit.Secret` (only ever in snapshot once the destination is discovered) | faint dotted `#8a7a55` (op ~0.6) + a `?` at midpoint |
| **One-way chute** | `oneway: true` | embossed line + **arrowhead** at ~0.72 toward the destination |
| **Gated arch** | exit is a threshold (`ExitMessage != ""`) | embossed line + a small **archway** (quadratic arc spanning the path, with post feet) at the midpoint |
| **Stairs** | `kind=vertical` | ▲/▼ tick on the room (no connector) |
| **Cross-zone road-out** | destination room is in a **different zone** | a labelled **stub to the border**: `"→ <Dest Zone>"` |
| **Unexplored exit** | exit to a not-yet-visited room | a dim dashed **stub** in the exit direction ("more this way") |

Biome path kind for a connector is chosen by precedence water → trail → road →
ridge → plain across the two endpoints' biomes.

## 6. Server changes (small — `internal/mapper` + `modules/gmcp`)

The mapper's `nodeExit` already carries `Secret`, `LockDifficulty`, `OneWay`,
`Direction`, and `RoomId`; `classifyKind` gives `normal/long/wrap/vertical`;
each room knows its `Biome` and `Zone`. Add to the snapshot:

1. **`SnapshotExit` flags:** `locked` (`LockDifficulty>0`), `secret`
   (`exit.Secret`), `oneway` (`exit.OneWay`), `gate` (`exit.ExitMessage != ""`
   — thread `ExitMessage`/a `Gate` bool through `getMapNode`→`nodeExit`), and
   `toZone` (destination zone name when it differs from the room's zone, else
   empty). `kind`/`dx`/`dy`/`dz` already present.
2. **Stub / cross-zone exits:** `Snapshot` currently drops exits whose
   destination isn't a visited same-zone room. Also emit those as **stub exits**
   (direction + `toZone` if cross-zone, or just a stub flag if simply unvisited)
   so the client can draw "more this way" stubs and the cross-zone label. (This
   is the unexplored-exit-stub + cross-zone feature.)
3. **Party positions:** add party-member room IDs (on the current floor) to the
   `GMCPZoneModule_Payload` (e.g. `party: [roomId,...]`), sourced from the
   party system + each member's `RoomId`.

`name`, `tags` (service), `symbol`, `biome`, and `cz` (current floor) already
ship from the hybrid chunk.

## 7. Client rewrite (`gmcp.js` `RoomGridSVG`)

This is effectively a **new render path** for the SVG. Keep the existing data
plumbing (`setZoneSnapshot`, floor filtering, two-pass node-then-edge placement,
fog, dedup sets, fit/center/zoom, controls). Replace the *drawing*:

- One-time per snapshot: build `<defs>` (leather gradient, grain filter,
  vignette, sheen, stain gradients, **hide clip-path**), draw the hide + rim,
  the clipped texture group (grain/sheen/stains/**craquelure**), then the
  embossed **border + corner studs + graticule**, **title** (zone + level),
  **compass**, and **legend**.
- Per room: token (normal/service/current per §3), `<title>` tooltip, stairs
  ticks, party figure, fog opacity. Current-room emphasis per §3.
- Per exit: route by the new flags + `kind` + biome to the connection renderers
  in §5 (road/trail/water/ridge/plain, long, locked door, secret, one-way, arch
  gate, cross-zone stub, unexplored stub). Reuse the emboss helpers.
- Emboss/fray/craquelure helpers (`embLine`/`embCirc`/`embText`,
  `hidePath`, `craquelure`, door/arch/arrow icon drawers) — port from the
  mockups (`01`/`02`/`03`).

Performance note: craquelure + emboss multiply element count; the mockups run
~1–2k SVG nodes per panel comfortably. Build the static surface (border/texture/
legend/compass) **once per snapshot** (or only when the zone/floor changes), not
per room, to keep moves cheap. The per-move full resend is the accepted tradeoff
([[project_zonemap_permove_resend_optimization]]); re-rendering the whole hide
each move is the main cost to watch — cache the static surface layer if needed.
