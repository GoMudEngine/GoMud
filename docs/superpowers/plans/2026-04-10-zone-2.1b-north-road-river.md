# Zone 2.1b: North Road River Approach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build 10 new rooms extending the North Road zone northward through river country toward Stillwater, with 2 friendly NPCs and ambient hostile mobs.

**Architecture:** Pure content — room YAMLs, mob YAMLs, dialogue YAMLs. No engine code changes. Rooms go in the existing `north_road/` zone folder. NPCs get dialogue files. Hostile mobs are simple templates.

**Tech Stack:** YAML data files

**Spec:** `docs/superpowers/specs/2026-04-10-zone-2.1b-north-road-river-design.md`

```bash

find _datafiles/world/dogmud/mobs -name "*.yaml" | sed 's/.*\///' | sed 's/-.*//' | sort -n | grep -v "^9" | tail -5
```
