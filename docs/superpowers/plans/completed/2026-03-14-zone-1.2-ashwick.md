# Zone 1.2: Ashwick — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Ashwick, a 20-room hamlet zone east of the Ashwick Crossroads, with 9 mobs, 3 items, 2 quests, 4 dialogue trees, and layered novel discovery content.

**Architecture:** Pure data-file zone — YAML rooms, mob definitions, dialogue trees, item definitions, quest configs, and JS scripts. No Go code changes. The zone connects east from existing room 4014 (Ashwick Crossroads).

**Tech Stack:** YAML data files, JavaScript mob/room scripts, GoMud engine conventions.

**Spec:** `docs/superpowers/specs/2026-03-14-zone-1.2-ashwick-design.md`

**Lessons from Zone 1.1:**
- Items in the 40000+ range go in `items/materials-40000/`, NOT `items/other-0/`
- Don't spawn hostile mobs in rooms where dialogue/negotiation should happen first
- All dialogue hints must avoid third-person self-references for the speaking NPC
- Always check for stale instance saves after modifying existing rooms
- Both `give <item> <npc>` AND `ask <npc> <topic>` (with requiresItem) must work for quest completion

- [ ] **Step 1: Write Delia onGive script (259-delia.js)**

Follow the Peddler Malk pattern from Zone 1.1:

```javascript
// Delia - Mob 259
// Handles give-based quest completion for Quest 16.
// Player can give forest herbs (item 40040) instead of dialogue.

var HERBS_ITEM_ID = 40040;

function onGive(mob, room, eventDetails) {

    if ( eventDetails.sourceType == "mob" ) { return false; }

    var user = GetUser(eventDetails.sourceId);
    if ( user == null ) { return false; }

    if ( !eventDetails.item || !eventDetails.item.ItemId ) {
        return false;
    }

    var itemId = eventDetails.item.ItemId;

    if ( itemId == HERBS_ITEM_ID ) {

        // Player found herbs before talking to Delia
        if ( !user.HasQuest("16-start") ) {
            user.GiveQuest("16-start");
            user.GiveQuest("16-end");
            mob.Command('say Where did you find these? '
                + 'This is feverfew and bitter-thistle of a '
                + 'quality I have not seen in months.', 1.0);
            mob.Command('say You have solved a problem I '
                + 'have been struggling with for weeks. '
                + 'Thank you.', 3.0);
            return true;
        }

        if ( user.HasQuest("16-end") ) {
            mob.Command('say I have what I need for now. '
                + 'But thank you.');
            return true;
        }

        // Normal completion
        user.GiveQuest("16-end");
        mob.Command('say These are remarkable. The color, '
            + 'the potency -- this is better than anything '
            + 'I have been able to cultivate.', 1.0);
        mob.Command('say My stock will be full again within '
            + 'the week. You have my gratitude.', 3.0);
        return true;
    }

    // Not the quest item
    mob.Command('say That is kind of you, but I have '
        + 'no use for it.');
    mob.Command('give !'
        + String(eventDetails.item.ItemId) + ' '
        + user.ShorthandId());
    return true;
}
```

- [ ] **Step 2: Write Maren's Cottage room script (4023.js)**

This script grants quest discovery tokens when players take items from the cottage containers:

```javascript
// Maren's Cottage - Room 4023
// Grants quest discovery tokens when players find hidden items.
// The letter (40041) and recipe (40042) are in containers
// (stone and drawer). This script fires on command to handle
// the quest token grants and flavor text.

var LETTER_ITEM_ID = 40041;
var RECIPE_ITEM_ID = 40042;

function onCommand(cmd, rest, user, room) {

    // The containers handle the actual item pickup.
    // We intercept to add quest tokens after pickup.
    // Check if player just acquired either item.

    if ( cmd == "get" || cmd == "take" ) {
        if ( rest == null || rest == "" ) { return false; }
        var target = rest.toLowerCase();

        // Letter discovery
        if ( target == "letter" || target == "creased letter" ) {
            if ( user.HasItemId(LETTER_ITEM_ID)
                 && !user.HasQuest("17-letter") ) {
                user.GiveQuest("17-letter");
                user.SendText('Behind the loose stone, '
                    + 'a small cavity holds a folded letter. '
                    + 'The paper is creased from years of '
                    + 'being read and refolded. Someone hid '
                    + 'this here deliberately.');
            }
            return false;
        }

        // Recipe discovery
        if ( target == "recipe" || target == "recipe page"
             || target == "page" ) {
            if ( user.HasItemId(RECIPE_ITEM_ID)
                 && !user.HasQuest("17-recipe") ) {
                user.GiveQuest("17-recipe");
                user.SendText('The drawer yields a single '
                    + 'page of careful handwriting -- a '
                    + 'technique you recognize from your own '
                    + 'studies. Seeing it written in another '
                    + 'hand clarifies something you had been '
                    + 'working toward.');
            }
            return false;
        }
    }

    return false;
}
```

Note: returning `false` lets the engine's default container pickup also process. The script adds the quest token and flavor text on top.
