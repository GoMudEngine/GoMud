## Standing author rules (bake into EVERY subagent prompt that writes YAML)

1. **No colon-space `": "` in prose** — YAML reads it as a key (load panic).
   Use an em-dash or reword.
2. **No semicolons in NPC dialogue `text:`/`hints:`** — `;` is a command
   separator in-game; text after it is dropped.
3. **Long NPC `text:` (≥~120 chars) must use `|` literal block scalars** —
   double-quoted flow scalars truncate in-game.
4. **Hard-wrap prose at ~78–80 chars**; never split a hyphenated compound
   across folded-scalar lines.
5. **Hinted multi-word nouns**: the ansi token AND the noun key must be the
   same hyphenated form the hint uses (`sealed-chamber`, not `chamber`).
6. Every hint keyword must route to a dialogue node (cross-check each one).
7. Room prose voice: second person, present tense, no hard numbers.
8. **Mob names must equal `casing.Title(name)`** — interior minor words
   (a, an, the, of, …) lowercase; first and last words always capitalized.
   Filename = `mobid-ConvertForFilename(name).yaml` (lowercase, keeps
   articles: "A Sewer Rat" → `9563-a_sewer_rat.yaml`).
9. **Terminus stubs must NOT invite `go <direction>`** — frame as
   not-passable (welded, collapsed, flooded, sealed).
10. **Lore boundary (threshold-only):** allowed — older-than-the-city,
    worked stone that doesn't match, gray material neither stone nor metal,
    a sealed chamber nobody opened. FORBIDDEN — ship/sky/moons/machine/
    vessel/crash, any explanation. The nested-rings symbol appears at most
    ONCE (faint, on the sealed chamber) and is never explained.
11. **Git: stage explicit pathspecs only. NEVER `git add -A`** (the working
    tree is dirty with economy snapshots/screenshots).

def coord_of(f):
    with open(f, encoding='utf-8') as fh: c = fh.read()
    m = re.search(r'coord:\s*\n\s*x:\s*(-?\d+)\s*\n\s*y:\s*(-?\d+)\s*\n\s*z:\s*(-?\d+)', c)
    return tuple(int(x) for x in m.groups()) if m else None

           (-24,82,-2)}
collisions = []
root = '_datafiles/world/dogmud/rooms'
for zone in os.listdir(root):
    p = os.path.join(root, zone)
    if not os.path.isdir(p): continue
    for f in os.listdir(p):
        if not f.endswith('.yaml') or not f[0].isdigit(): continue
