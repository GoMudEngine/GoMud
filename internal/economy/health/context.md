# Economy Health Context

## Purpose

`internal/economy/health` is the observability layer for the living economy. It
periodically photographs the whole economic world — every shop's stock and
gold, every caravan and ferry factor's position, every warehouse, every
forager — writes those snapshots to disk, and scores them so a human can tell
whether the economy is healthy without reading raw numbers.

It is **read-only with respect to the economy**. Nothing here restocks, prices,
or moves goods; it only measures.

## Files

- **snapshot.go** — the snapshot data shapes.
- **capture.go** — walks the live world and builds a `Snapshot`.
- **persistence.go** — write/load/list/prune snapshots on disk.
- **delta.go** — compare two snapshots.
- **scoring.go** — turn snapshots into health scores (the largest file).
- **util.go** — small sort helper.

## Snapshot model

```go
type Snapshot struct {
    /* timestamp, round, plus: */
    // []ShopSnapshot, []CaravanSnapshot, []WarehouseSnapshot, []ForagerSnapshot
}
```

`CaravanSnapshot` covers **both** caravans and ferry factors —
`captureFerryFactors()` produces the same shape as `captureCaravans()`
deliberately, so the scoring code treats "a thing that hauls goods on a cycle"
uniformly.

`ShopSnapshot` carries per-item `StockSnapshot` entries and a `StockEvent`
history, which is what makes time-to-restock measurable.

## Capture and persistence

```go
func CaptureSnapshot() Snapshot

func WriteSnapshot(s Snapshot) error
func LoadSnapshot(unixTs int64) (*Snapshot, error)
func ListSnapshots() []SnapshotMeta
func PruneSnapshots(retentionDays int) (int, error)
func SnapshotFilename(unixTs int64) string
```

Each function has a `*To` / `*From` / `*In` variant taking an explicit
directory, which is how the tests avoid the real snapshot folder.

Snapshots are **runtime state, regenerated by the server** and gitignored
(`_datafiles/**/economy/snapshots/`).

## Deltas

```go
func PickClosestSnapshot(metas []SnapshotMeta, target int64, toleranceSeconds int64) *SnapshotMeta
func FindShopInSnapshot(s *Snapshot, zone string, mobId, roomId int) *ShopSnapshot
func FindForagerInSnapshot(s *Snapshot, mobId int) *ForagerSnapshot
func FindCaravanInSnapshot(s *Snapshot, instId int) *CaravanSnapshot
func ComputeShopDelta(now ShopSnapshot, old *ShopSnapshot) ShopDelta
func ComputeForagerDelta(now ForagerSnapshot, old *ForagerSnapshot) ForagerDelta
func ComputeCaravanDelta(now CaravanSnapshot, old *CaravanSnapshot) CaravanDelta
```

`PickClosestSnapshot` exists because snapshots are taken on a timer, not on
demand: "compare against 24 hours ago" has to mean "the nearest snapshot within
tolerance."

Every `Compute*Delta` accepts a **nil** `old` — that is the first-run case, and
it must produce a usable zero delta rather than panic.

## Scoring

```go
type ScoringConfig struct { /* thresholds, targets, weights */ }
func ScoringConfigFromBalance() ScoringConfig

func Score(cur *Snapshot, history []*Snapshot) Scores
func ScoreWithConfig(cur *Snapshot, history []*Snapshot, cfg ScoringConfig) Scores
```

`Scores` aggregates several independent signals:

- **`StockScore` / `ShopGoldScore` / `PerShopScore`** — is a shop stocked, and
  does it have gold to buy with.
- **`ThroughputScore`** — time-to-restock against a per-rarity-tier target
  (`ttrTargetRounds`, `cadenceHoursForTier`).
- **`InputRateScore`** — is raw material entering a zone fast enough
  (`zoneInputTarget`, matched to territory via `territoryMatchesZone`).
- **`PerCaravanScore` / `PerForagerScore`** — completed cycles over the history
  window, counted by `countStateReturns` watching the entity return to a target
  state.
- **`LogisticsHealth`** — the combined haulage picture.
- **`PerCraftSupportScores`** — whether each crafting trade can actually buy
  its inputs.

The `*Opt` variants (`StockScoreOpt`, `PerShopScoreOpt`) return
`(score, ok)` so a shop with nothing to measure is **excluded** from an average
instead of scoring zero and dragging it down.

## Gotchas

- **Cycle counts come from state transitions, not counters.**
  `CountCaravanCycles` / `CountForagerCycles` count returns to a target state
  across the snapshot history, so a history window shorter than one cycle
  reports zero cycles — which looks identical to "broken". Check the window
  before concluding a caravan is stuck.
- **`isDespawnedState` is how a dead entity is excluded.** An entity that is
  merely still loading at boot can read as despawned; the dashboard has a known
  rough edge here (no boot grace period).
- **Scoring reads config through `ScoringConfigFromBalance()`.** Tests should
  build a `ScoringConfig` and call `ScoreWithConfig`, not mutate global config.
- **Snapshot capture walks the entire world.** It is not cheap; it belongs on a
  timer, never on a player-facing path.
- **Median time-to-restock is computed twice** — `computeMedianTtRForTiers` in
  capture and `computeMedianTtR` in delta. They serve different windows; do not
  assume they agree.
