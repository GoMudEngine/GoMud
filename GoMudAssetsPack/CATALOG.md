# GoMudAssetsPack — Icon Catalog

112 community-made item icons (credit: GoMud community member; reuse OK).
Reorganized by type/equipment-slot; filenames are the **upstream GoMud item
names**, with the upstream item ID kept for provenance. These are icon
*depictions* — map them to DOGMud items by type/appearance (our item IDs
differ from upstream). Generated from $HOME/GoMud item data 2026-06-08.
